# Enterprise Income Category Ledger (React + Vite)

An Enterprise Income Category Registration and Ledger application built using React, Vite, and Bootstrap 5, based on Applied Lab 1.

---

## 🌐 Live Deliverables & Project Links

* **Vercel Production Deployment:** https://react-js-theta-eight.vercel.app
* **GitHub Repository:** https://github.com/kcaballero250000000510-wq/ReactJS

---

## 🛠️ Architecture & Tech Stack

* **Framework:** React 18 (Vite build tool)
* **Styling:** Bootstrap 5 (CDN)
* **Hosting:** Vercel (Continuous Deployment from `main` branch) & GitHub Pages (`gh-pages`)
* **State Management:** Refactored vanilla DOM manipulation (`document.getElementById`, `insertAdjacentHTML`) from Applied Lab 1 into dynamic React state (`useState`) and reference management (`useRef`).
